# Agenda Acadêmica

Aplicação web para estudantes organizarem trabalhos, provas e atividades de diferentes disciplinas em uma única lista, acompanhando prazos e o que já foi concluído.

Projeto desenvolvido para a PIT — Projeto Integrador Transdisciplinar.
**Autor:** Gustavo Emanoel Bianchini — RGM 33636541

## Tecnologias

| Camada | Tecnologia |
| --- | --- |
| Back-end | Python 3 (biblioteca padrão, `http.server`) |
| Banco de dados | SQLite |
| Front-end | HTML, CSS e JavaScript (sem frameworks) |
| Plataforma | Web, responsiva (computador e celular) |
| Modo de codificação | Tradicional |

## Estrutura do repositório

```
versao-1/   código da primeira versão (v1.0)
docs/       documentação do projeto e laudo de qualidade
```

## Executar a versão 1

```bash
cd versao-1
python3 app.py
```

Depois, acesse `http://127.0.0.1:8000`. Mais detalhes em [`versao-1/README.md`](versao-1/README.md).
